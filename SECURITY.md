# Политика за сигурност / Security Policy

## Поддържани версии / Supported versions

Поправки по сигурността се издават само за **последната версия** в
[GitHub Releases](https://github.com/plam4o4o-source/yavorec-katalog/releases).
Програмата се обновява автоматично, затова реално всички инсталации следват
последното издание.

Security fixes are released only for the **latest release**. The
application auto-updates, so in practice all installations track the
latest version.

## Докладване на уязвимост / Reporting a vulnerability

**Не отваряйте публичен issue за уязвимост.** Предпочитаният канал е
**GitHub Security Advisories** — частен доклад, който виждат само
поддържащите проекта:

1. Отворете <https://github.com/plam4o4o-source/yavorec-katalog/security/advisories>
2. Натиснете **„Report a vulnerability“** и опишете: засегнатата версия,
   стъпки за възпроизвеждане и какво е въздействието (какви данни/действия
   стават достъпни).

**Please do not open a public issue for a vulnerability.** Use GitHub
Security Advisories (link above) — a private report visible only to the
maintainers. Include the affected version, reproduction steps, and impact.

Ще получите отговор във възможно най-кратък срок (обикновено до няколко
дни). Поправката се публикува като ново издание, а подробностите се
оповестяват в CHANGELOG след като обновяването е достъпно.

## Какво е в обхвата / Scope

„Инвентар“ е **офлайн десктоп програма**: данните стоят в локален SQLite
файл на компютъра (или в споделена папка в локалната мрежа) и не се
изпращат към външни сървъри. В обхвата на политиката влизат например:

- достъп до лични данни на читатели (ЕГН/№ на лична карта са шифровани с
  парола — заобикаляне на тази защита е уязвимост);
- инжекция през полета за въвеждане или през внасяни файлове
  (CSV/XLSX/MARC), която води до изпълнение на код;
- проблеми в публикувания онлайн каталог (`katalog.json` /
  `site/page-katalog.html`) — напр. изтичане на данни на читатели или XSS
  на страницата на каталога;
- проблеми в процеса на автоматично обновяване.

Извън обхвата: необходимостта от достъп до самия компютър на библиотекаря
(програмата не претендира за защита срещу човек с физически достъп и
администраторски права), както и фалшивите тревоги на антивирусни програми
(вижте [раздела в наръчника](electron-app/README-bibliotekar.md#цифров-подпис-и-антивирусни-програми)).
